1. 앤트로픽 (Anthropic) 및 클로드 모델 소식

  • 클로드 내부 웹 환경에서 'Fable 5.5'의 프로덕션 체크포인트 경로(/home/Anthropic/Models/Fable/Fable5-5/production/checkpoints/2026-10-25/)가 발견되었다는 주장이 제기되었습니다. (한 유저 주장)
  • 커뮤니티 내부에서는 Fable 5.5의 출시일을 10월 27일 또는 11월 초로 점치고 있습니다. (루머)
  • 최근 클로드 웹 및 Claude Code(CC), Agents SDK 사용 시 주간·5시간 사용량 제한이 비정상적으로 빠르게 소진되는 현상이 보고되고 있습니다.
  • 사용량 급증 현상에 대해 내부 관계자(Boris)가 의도된 변경 사항이 아니라고 밝혔다는 언급이 있어 단순 버그일 가능성이 제기되고 있습니다.
  • 최신 클로드 모델에서 저작권이 있는 디자인 복제나 리버스 엔지니어링(REA) 관련 프롬프트에 대한 거부 및 검열 기준이 한층 강화되었다는 관측이 나왔습니다. (한 유저 주장)
  • Opus 5.5의 추론 노력도(Effort Level) 설정과 관련해, 비용 대비 효율은 '중간(Medium)', 결과물의 깔끔함은 '높음(High)'이 가장 안정적이라는 실사용자 피드백이 공유되었습니다.

2. 오픈AI (OpenAI) 및 관련 기능 소식

  • 이미지 생성 모델 테스트 환경에서 gpt-image-2.5-sunburst, gpt-image-2.5-moderation-sunburst 등의 모델 식별자가 포착되었습니다. (한 유저 주장)
  • ChatGPT 웹 환경에서 네이티브로 제공되던 메시지 대기열(Queue) 기능이 비활성화되어 별도 확장 프로그램을 사용해야 한다는 지적이 나왔습니다.
  • 코딩 작업 시 GPT 모델이 통합 테스트나 엔드투엔드(E2E) 테스트 없이 깨지기 쉬운 단위 테스트(Unit test)를 과도하게 작성하는 경향이 있어, 다른 모델을 오케스트레이터로 함께 쓰는 방식이 권장된다는 평가가 있습니다.
  • 인라인 코드 작성 중 다음 입력을 유추하는 Codex 텍스트 예측 기능이 실사용에서 준수한 정확도를 보이고 있다는 실사용 평가가 공유되었습니다.
