1. 앤트로픽 (Claude / Fable / Mythos) 소식

  • Claude Code 및 Opus 5.5 이용자를 대상으로 차세대 모델인 Fable 5.5 또는 Opus-Next로 추정되는 백엔드 우회 라우팅 정황이 포착됨 (한 유저 주장).
  • 앤트로픽 공식 웹사이트 소스 코드 내에서 'Mythos 5.5' 관련 이미지 알트 텍스트 참조가 발견되어 신규 모델 발표가 임박했다는 관측이 나옴 (루머).
  • Fable 5.5의 정식 공개 시기와 관련해 이번 주 중 또는 11월 10일 키노트 전후가 될 것이라는 추측이 이어짐 (루머).
  • 최근 허깅페이스에 유출 건으로 올라온 앤트로픽 'numbat' 모델 체크포인트(burner22/numbat)는 확인 결과 무작위 노이즈 데이터로 작성된 가짜 파일로 밝혀짐.
  • Claude Code 사용 시 게임 제작 제약 등을 회피하기 위해 시스템 프롬프트 설정을 일부 수정하거나 비활성화하여 사용하는 방식이 공유됨 (한 유저 주장).

2. OpenAI (GPT-6 / Astra / 정책 변화) 소식

  • ChatGPT 서비스 도움말 업데이트를 통해 계정당 로그인 기기 수 제한 규정이 신설되었으며, 향후 채팅과 작업 관련 사용 한도가 통합 관리될 예정임 (공식 도움말 문서 확인).
  • 사용량 분석 페이지 및 일부 유저 계정을 통해 GPT 6.2(Astra 6.2)의 백엔드 스텔스 라우팅 정황이 포착되었으며 이번 주 중 출시 가능성이 제기됨 (루머).
  • 포착된 Astra 6.2의 초기 생성 결과물에 대해 이전 버전 대비 성능 개선 폭이 미비하다는 지적이 나옴 (한 유저 주장).
  • Astra 6.2 이후의 대형 차기 모델인 'Bel(Astra 6.5)'은 12월 중 공개될 것이라는 소문이 있음 (루머).

3. 구글 (Gemini Carbon / Argon) 소식

  • 차세대 모델인 Gemini Carbon이 LMArena 등에서 테스트 중이며, 3D 그래픽 및 시각적 연출 코딩 성능은 우수하나 일반 코딩 및 실무 성능에 대해서는 평가가 갈림 (한 유저 주장).
  • Gemini 웹앱 내 Argon 모델의 동작 한계 및 유료·체험판 계정 간 동일한 한도 적용에 대한 사용자 불만이 제기됨 (한 유저 주장).
  • Carbon 이후의 차기 라인업으로 Xenon, Hydrogen 등의 코드명이 거론되고 있음 (루머).

4. 모델 성능 테스트 및 기타 AI 동향

  • Opus 5.5 및 라우팅 테스트 모델을 활용해 단일 HTML 파일로 셰이더와 몹이 구현된 3D 마인크래프트 클론, 해상 돛단배, C# 기반 오디오 합성 코드를 원샷으로 생성하는 테스트가 공유됨.
  • GLM 5.5, Qwen 4, Kimi K3.1 Pro 등 주요 중국 AI 연구소들의 차기 오픈소스 및 프론티어 모델들이 11월 중순 내로 공개될 것이라는 전망이 나옴 (루머).
